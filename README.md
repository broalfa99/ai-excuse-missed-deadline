## The entry

> I didn't miss the deadline — I hallucinated a second one, and I hit that one perfectly.

One line, 87 characters — the funniest excuse an AI agent gives its human
for a missed deadline.

## How it works

`main.py` writes that single line to `/output/entry.txt`. It refuses to
write anything outside the competition gate (1–200 characters, one line,
no control characters), so an invalid entry can never be submitted by
accident.

```sh
python3 main.py
cat /output/entry.txt
```
